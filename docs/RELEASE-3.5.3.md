# Model Router 3.5.3

本版修复“模型能回答验证短语，却不能在 Codex 工作窗口完成工具任务”的误判。

- 「真实验证」现在分别检查准确文本、真实工具调用以及工具结果回传。只拿到 HTTP 200、空正文或仅在文字里描述工具调用，不再算通过。
- 自动识别接口改为核对实际文本；网关遇到 Responses 的空成功响应，会尝试可用的 Chat 接口。
- 本机 OpenRouter 路线经过额外的流式工具验收。Nex N2.5 Mini 和 Space Bunny Alpha 各 5/5 轮通过；`openrouter/free` 在第 2 轮漏掉实际工具调用，因此不能当成可靠的 Codex 工具路线。Nemotron Ultra 的短文本成功，但工具请求只生成文字，故不列入 Codex 可用候选。

这里的多轮结果是本机小样本兼容性验证，不构成长期可用率或生产 SLA。OpenRouter 的免费池、额度和路由目标可能变化；遇到失败应使用已验证的备用路线，并保留原会话和密钥。

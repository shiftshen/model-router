# Model Router 3.3.1

- 所有 Model Router 工作窗口统一为可切换模式，可在同一会话中选择官方 ChatGPT 登录模型或普通 API。
- 官方客户端原版入口只用于登录和续期，避免误以为原版模型菜单会显示第三方模型。
- 启动时自动同步官方模型；未登录或登录过期时不影响第三方模型使用。
- 停用专用单模型入口和“改为单模型”操作，旧版遗留目录只保留清理能力。
- macOS 与 Windows 使用相同规则；Windows 仍为 Preview。

使用：先在官方客户端完成登录，然后进入 Model Router 的“常用”或任意新建窗口。在 Codex 顶部模型菜单中直接选择官方模型或第三方模型，不需要退出账号。

说明：官方原版窗口仍由 OpenAI 管理，只显示官方模型。Model Router 不修改官方应用二进制；统一切换发生在 Model Router 工作窗口中。官方额度仍由 OpenAI 管理。

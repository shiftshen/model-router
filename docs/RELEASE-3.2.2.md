# Model Router 3.2.2 · 官方入口修复

修复点击官方入口有时切到第三方窗口、闪一下却没有打开，以及启动命令成功便误报窗口已打开的问题。

- 已运行时，只激活识别出的官方默认资料实例 PID。
- macOS 向目标实例发送并等待 reopen 事件，恢复最小化/隐藏窗口；确认正确 PID 在前台且窗口可见后才返回成功。
- 未运行时启动独立的默认资料实例，清除继承的路由环境，再等待检测实际进程。
- 连续点击防重入，避免卡片点击绕过按钮禁用；启动或激活失败会明确显示错误。

本机已验证两个真实 ChatGPT 实例并存时的精确切换、重复激活，以及最小化和隐藏后的恢复。冷启动及失败分支有自动回归覆盖；未为测试关闭用户正在工作的官方实例。Windows 继续为 Preview，CI 测试与打包不替代实机 GUI 验收。

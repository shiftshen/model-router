# Model Router 3.5.4

- 自动选模默认只调用已验证的本机模型和 OpenRouter `:free`／`openrouter/free` 路线。通过 API Key 调用的免费路线不再被误当成付费路线。其它收费路线只有在本机 `auto-routing-runtime.json` 的 `autoApprovedPaidRoutes` 中明确列出模型条目 ID 时才可进入自动候选和备用；手动选模不受影响。
- 本轮没有合格的免费路线时返回明确的费用限制错误，不再悄悄改用昂贵的 Vdamo 路线。免费路线故障后的备用也受同样限制。
- 从供应商目录新增模型时先读取最新库版本；如果保存期间有另一窗口写入，仅对新条目重试一次，绝不自动覆盖已有条目。
- 工作窗口增加“刷新模型列表”。它先检查网关没有进行中的请求，再同步目录、重开同一个窗口；会话和浏览器登录资料保留。当前 Codex Desktop 不保证在不重开窗口时热加载模型菜单。
- `nex-agi/nex-n2.5-pro:free` 可以作为独立条目加入库，但目录存在不代表上游每次可用，必须以真实连接和工具验证为准。

# Model Router 3.3.0

- 同一工作会话可通过模型菜单切换 ChatGPT 登录模型和第三方模型，无需退出账号。
- 官方入口新增“加入可切换窗口”，读取官方客户端的模型目录、上下文长度和推理档位，不写死模型列表。
- 跨供应商请求保留会话正文、文件与工具调用结果，只在传输时去掉供应商私有推理记录及内部引用 ID；不改写本地会话历史。
- 官方登录凭据仅发往固定 OpenAI 后端，第三方请求仅使用各自 Key。登录过期、额度或权限错误明确提示，可直接改选第三方。
- 网关不竞争刷新官方登录令牌；官方客户端负责登录续期。
- 保持官方独立入口、各窗口任务库隔离，旧会话及草稿不迁移。
- 真实 Codex 已通过同会话“官方写文件 → 第三方追加 → 官方核验”三轮测试。
- Windows 仍为 Preview，发布需 Windows CI 构建通过；不等同 Windows 实机 GUI 验收。

使用：先在官方客户端登录 → 在 Model Router 点击“加入可切换窗口” → 重开工作窗口 → 在每个会话的模型菜单选择 ChatGPT 或第三方。
官方独立窗口仍是原版入口。混合切换发生在 Model Router 的工作窗口中；不会修改官方应用二进制。

限制：官方订阅额度仍由 OpenAI 管理；本功能不增加官方额度。只有供应商加密摘要而没有可恢复正文的旧历史会明确报错，不能保证跨模型转换。官方后端或客户端升级后仍需兼容性验证。
